# 🚩 เมทอดที่ใช้ในการทำงาน

## SGT_Area.getRegion() 
- จะ return Array ของชื่อและตำแหน่งที่ใช้อ้างอิงไปยังภูมิภาคนั้น ๆ ออกมา
- ตัวอย่างของข้อมูลที่ return ออกมา
  ```js
    [
      {
        name: "มหานคร 1",
        pos: 0
      },
      // ...ข้อมูลภูมิภาคอื่น ๆ
    ]
  ```

## SGT_Area.getZone(rg_pos)
- จะทำการรับตำแหน่งที่ใช้อ้างอิงไปยังภูมิภาคเข้ามาเพื่อใช้ในการอ้างอิง
- และจะ return Array ของชื่อและตำแหน่งที่ใช้อ้างอิงไปยังรวมภาค ที่อยู่ในภูมิภาคนั้น ๆ ออกมา
- ตัวอย่างของข้อมูลที่ return ออกมา
  ```js
  [
    {
      name: "กรุงเทพ 1",
      pos: 0
    },
    // ...ข้อมูลรวมภาคอื่น ๆ
  ]
  ```
    
## SGT_Area.getSector(rg_pos, zone_pos)
- จะทำการรับตำแหน่งที่ใช้อ้างอิงไปยังภูมิภาคและรวมภาคเข้ามาเพื่อใช้ในการอ้างอิง
- และจะ return Array ของชื่อและตำแหน่งที่ใช้อ้างอิงไปยังภาค ที่อยู่ในรวมภาคนั้น ๆ ออกมา
- ตัวอย่างของข้อมูลที่ return ออกมา
  ```js
  [
    {
      name: "นนทบุรี",
      pos: 0
    },
    // ...ข้อมูลภาคอื่น ๆ
  ]
  ```

## SGT_Area.getDistrict(rg_pos, zone_pos, sec_pos)
- ทำการรับตำแหน่งที่ใช้อ้างอิงไปยังภูมิภาค รวมภาค และภาคเข้ามาเพื่อใช้ในการอ้างอิง
- return Array ของชื่อและตำแหน่งที่ใช้อ้างอิงไปยังเขต ที่อยู่ในภาคนั้น ๆ ออกมา
- ตัวอย่างของข้อมูลที่ return ออกมา
  ```js
  [
    {
      name: "บางซื่อ",
      pos: 1
    },
    // ... ข้อมูลเขตอื่น ๆ
  ]
  ```

# 🆕 รายละเอียดการ Update

## <a name="detail-2025"></a> 🟢 Update 2025.02
### 1. กลุ่มรวมภาคใต้
* **รวมภาคใต้ 1**
    * แยก **ภาคสันติธรรม** ออกเป็น:
        * ภาคเขาชัยสน (เขตกงหรา, ป่าบอน, เมืองพัทลุง)
        * ภาคควนขนุน (เขตดอนทราย, ป่าพะยอม)
    * **ภาคปิติธรรม**: เพิ่มเขตแหลมโพธิ์
    * แยก **ภาคภักดีธรรม** ออกเป็น:
        * ภาคสะเดา (เขตปาดังเบซาร์, เมืองสะเดา)
        * ภาคหาดใหญ่ 1 (เขตสันติสุข, หาดใหญ่ใน)
        * ภาคหาดใหญ่ 2 (เขตทุ่งเสา, พะตง)
* **รวมภาคใต้ 4**
    * **ภาคคีรีรัตน์**: เพิ่มภาคใหม่ (เขตสุขสามวัง)
    * **ภาคพิปูน**: เปลี่ยนชื่อเขตพิปูน เป็น "เมืองพิปูน"
* **รวมภาคใต้ 8**
    * **ภาคกระบุรี**: เปลี่ยนชื่อเขตพื้นที่ทุกเขต
    * **ภาคระนอง**: เปลี่ยนชื่อเขตทรายทอง เป็น "เขตบางนอน"
    * **ภาคละอุ่น**: 
        * เปลี่ยนชื่อเขตเพชรบางพรวด เป็น "เขตบางพรวด"
        * เปลี่ยนชื่อเขตเพชรลำเลียง เป็น "เขตลำเลียง"

### 2. กลุ่มรวมภาคเหนือ
* **รวมภาคเหนือ 1**
    * **ภาคภูพิงค์**: เพิ่มเขตแม่แตง และเขตแม่ฮ่องสอน

### 3. กลุ่มรวมภาคอีสาน
* **การแยกกลุ่มงานหลัก (Split)**
    * แยก **รวมภาคอีสาน 1** ออกเป็น: รวมภาคอีสาน 1 (เดิม) และ รวมภาคอีสาน 8 (บุรีรัมย์ 1, 2)
    * แยก **รวมภาคอีสาน 2** ออกเป็น: รวมภาคอีสาน 2 (เดิม) และ รวมภาคอีสาน 10 (บ้านดุง, หนองคาย, อุดรธานี 2)
    * แยก **รวมภาคอีสาน 6** ออกเป็น: รวมภาคอีสาน 6 (เดิม) และ รวมภาคอีสาน 9 (โพนทอง, มุกดาหาร)
* **การปรับปรุงรายภาค**
    * **รวมภาคอีสาน 3**: 
        * ภาคขอนแก่น: เพิ่มเขตบ้านไผ่
        * ภาคมหาสารคาม: เพิ่มเขตโกสุมพิสัย
        * ภาคร้อยเอ็ด 1: เพิ่มภาคใหม่ (เขตจังหาร)
    * **รวมภาคอีสาน 4**: 
        * แยกภาคศรีสะเกษ ออกเป็น: ภาคศรีสะเกษ และ ภาคอุทุมพร (เขตศิลาลาด, อุทุมพร)
    * **รวมภาคอีสาน 5**: 
        * ภาคบึงกาฬ: เพิ่มเขตปากคาด และเขตพรเจริญ
        * ภาคสกลนคร: เพิ่มเขตนาหว้า, เรณูนคร, วังน้ำขาว และเปลี่ยนชื่อเขตคำบิด เป็น "เขตคำบ่อ"
    * **รวมภาคอีสาน 6**: 
        * ภาคร้อยเอ็ด: เพิ่มเขตเกษตรวิสัย
